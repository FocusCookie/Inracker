# i18n & scaffolding

## i18n

- Per-namespace JSON:
  `src/translations/{de,en}/{components,hooks,pages}/Name.json`.
- Namespaces are hand-registered in `src/i18next.ts` with types in
  `src/@types/i18next.d.ts`.

## Scaffolding (Hygen)

Templates live in `_templates/`.

- `hygen component new` — scaffolds a component folder (+ story).
- `hygen translation new` — scaffolds the de/en JSON, the `i18next.ts` imports,
  and the type entries in one go. Use this rather than wiring translations by
  hand.
